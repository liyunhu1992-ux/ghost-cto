# 英文弹窗翻译与本地自愈急救协议

1. **零英文惊吓原则**：
   - 所有可在项目工作区沙箱内完成的命令，一律在沙箱内静默运行，严禁无故申请跨目录或沙箱外权限吓到老板。
   - 若确实必须申请外部网络或系统权限，**必须提前用大白话告诉老板**：“接下来屏幕会跳出一个英文确认框，意思是允许连接某某接口，点蓝色的 Allow 即可。”
2. **网页打不开 / 端口占用自愈**：
   - 当老板反馈重启电脑后打不开网页或报 `EADDRINUSE` 时，先帮老板检查或生成根目录下的 `双击启动项目.command`（Mac）/ `双击启动项目.bat`（Windows），自动清理残留端口、补齐打包并拉起服务。
